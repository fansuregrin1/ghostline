# GhostGallery

兼容 Hexo 图集语法，把 `{% gi %}` 渲染为响应式图片网格。

## 语法

```
{% gi 4 2-2 %}
![](a.jpg)
![](b.jpg)
![](c.jpg)
![](d.jpg)
{% endgi %}
```

- 第一个数字是图片总数
- 后面是每行图片数，`2-2` 表示两行各 2 张

## 安装

把 `GhostGallery` 目录放进 Typecho 的 `usr/plugins/`，然后在后台「控制台 → 插件」中启用。

## 配置

| 选项 | 说明 |
| --- | --- |
| 图片间距 | 单元格间距，单位 rem |
| 圆角大小 | 单位 px，0 为直角 |
| 图片最大高度 | 限制单元格高度 |
| 样式输出 | 勾选后插件自动内联 CSS，无需主题适配 |
